# JINX EmbyClient

JINX EmbyClient 是一个面向 Windows 的第三方 Emby 桌面客户端。

> This project is an unofficial third-party client for personal Emby Server use. It is not affiliated with, endorsed by, or sponsored by Emby LLC.

## 发布方式

此仓库用于闭源分发说明和 Release 包发布，不公开应用源代码。当前源码版权保留：Copyright (c) 2026 SeriousQY. All rights reserved.

## 下载

请从 GitHub Releases 下载：

- 便携版：`JINXClient-win-x64.zip`
- 安装版：`JINXClient-Setup.exe`

## 第三方组件

发布包包含或可使用 mpv、Anime4K、WPF-UI、CommunityToolkit.Mvvm 和 .NET Runtime 等第三方组件。对应许可和声明见 `THIRD-PARTY-NOTICES.md`，发布包内也会随附该文件。
